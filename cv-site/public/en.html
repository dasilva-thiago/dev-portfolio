Projects

eduAssets - Equipment Management System

Full-stack application to digitize equipment loan, return, and incident tracking based on a real problem in a school environment, with control software and working hardware using Raspberry Pi and RFID. Controls all equipment at a public school in Pindamonhangaba (192 devices), with more than 66 tickets handled from the testing phase through November 5, 2026; the system generates reports used weekly to declare inventory to inspectors and agents of the State of São Paulo. REST APIs, endpoints, validations, and business rules with Node.js and Express; PostgreSQL database modeled with Prisma, including relationships, entity states, and data consistency rules. Application structured with separation of responsibilities, access control, and a focus on maintainability, clarity, and code evolution, using Git for version control and AI tools to support development, technical analysis, and documentation. Hosting configured by me on an Ubuntu VM on Oracle Cloud, with the application running in Docker and frequent use of CI/CD and deployment.

TypeScript, Node.js, Express, PostgreSQL, Prisma, Vite, REST API, Git, Raspberry Pi, RFID

Buenos Aires Explorer

Desktop application in C# and Windows Forms for registering points of interest in Buenos Aires and planning visit itineraries, with version 1.0.0 published. Persistence with Entity Framework Core and SQLite, with migrations and code organized in layers (Models, Services, Views, UI, and Data). Integration with external APIs: forward and reverse geocoding through the Nominatim API (OpenStreetMap) and image search on Wikimedia/Wikipedia. Distance calculation between stops with the Haversine formula, interactive itinerary map with Leaflet.js through WebView2, PDF export with QuestPDF, and custom interface components.

C#, .NET 10, Windows Forms, Entity Framework Core, SQLite, WebView2, Leaflet.js, QuestPDF, Nominatim API, Wikimedia API
