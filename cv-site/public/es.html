Proyectos

eduAssets - Sistema de Gestión de Equipos

Aplicación full stack para digitalizar el control de préstamos, devoluciones e incidencias de equipos a partir de una necesidad real del entorno escolar, con software de control y hardware funcional con Raspberry Pi y RFID. Control de todos los equipos de una escuela estatal en Pindamonhangaba (192 equipos), con más de 66 solicitudes atendidas desde la fase de pruebas hasta el 05/11/2026. Los informes generados por el sistema se usan semanalmente para declarar el inventario a inspectores y agentes del Estado de São Paulo. APIs REST, endpoints, validaciones y reglas de negocio con Node.js y Express; modelado de la base de datos PostgreSQL con Prisma, incluyendo relaciones, estados de las entidades y reglas de integridad. Aplicación estructurada con separación de responsabilidades, control de acceso y enfoque en mantenibilidad, claridad y evolución del código, con Git para el control de versiones y herramientas de IA como apoyo al desarrollo, análisis técnico y documentación. Alojamiento configurado por mí en una VM Ubuntu en Oracle Cloud, con la aplicación ejecutándose en Docker y uso frecuente de CI/CD y despliegue.

TypeScript, Node.js, Express, PostgreSQL, Prisma, Vite, REST API, Git, Raspberry Pi, RFID

Buenos Aires Explorer

Aplicación de escritorio en C# y Windows Forms para registrar puntos de interés en Buenos Aires y planificar itinerarios de visita, con la versión 1.0.0 publicada. Persistencia con Entity Framework Core y SQLite, con migraciones y código organizado en capas (Models, Services, Views, UI y Data). Integración con APIs externas: geocodificación directa e inversa con la API Nominatim (OpenStreetMap) y búsqueda de imágenes en Wikimedia/Wikipedia. Cálculo de distancia entre paradas con la fórmula de Haversine, mapa interactivo del itinerario con Leaflet.js mediante WebView2, exportación a PDF con QuestPDF y componentes de interfaz personalizados.

C#, .NET 10, Windows Forms, Entity Framework Core, SQLite, WebView2, Leaflet.js, QuestPDF, Nominatim API, Wikimedia API
