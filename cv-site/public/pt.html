Projetos

eduAssets - Sistema de Gestão de Equipamentos

Aplicação full stack para digitalizar o controle de empréstimos, devoluções e ocorrências de equipamentos a partir de um problema real do ambiente escolar, com software de controle e hardware funcional com Raspberry Pi e RFID. Controle de todos os equipamentos de uma escola estadual em Pindamonhangaba (192 equipamentos), com mais de 66 chamados atendidos desde a fase de testes até 05/11/2026. Relatórios gerados pelo sistema usados semanalmente para declarar o estoque a fiscais e agentes do Estado de São Paulo. APIs REST, endpoints, validações e regras de negócio com Node.js e Express; modelagem do banco PostgreSQL com Prisma, incluindo relacionamentos, estados das entidades e regras de consistência. Aplicação estruturada com separação de responsabilidades, controle de acesso e foco em manutenção, clareza e evolução do código, com Git para versionamento e ferramentas de IA como apoio ao desenvolvimento, análise técnica e documentação. Hospedagem configurada por mim em uma VM Ubuntu na Oracle Cloud, com a aplicação rodando em Docker e uso frequente de CI/CD e deploy.

TypeScript, Node.js, Express, PostgreSQL, Prisma, Vite, REST API, Git, Raspberry Pi, RFID

Buenos Aires Explorer

Aplicação desktop em C# e Windows Forms para cadastrar pontos de interesse em Buenos Aires e planejar roteiros de visita, com a versão 1.0.0 publicada. Persistência com Entity Framework Core e SQLite, com migrations e código organizado em camadas (Models, Services, Views, UI e Data). Integração com APIs externas: geocodificação e geocodificação reversa pela API Nominatim (OpenStreetMap) e busca de imagens na Wikimedia/Wikipedia. Cálculo de distância entre paradas com a fórmula de Haversine, mapa interativo do roteiro com Leaflet.js via WebView2, exportação para PDF com QuestPDF e componentes de interface personalizados.

C#, .NET 10, Windows Forms, Entity Framework Core, SQLite, WebView2, Leaflet.js, QuestPDF, Nominatim API, Wikimedia API
